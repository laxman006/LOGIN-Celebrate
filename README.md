# Claude Hub

A web application built with **Next.js** and **Capacitor**, supporting both web and native Android deployment.

## Tech Stack

| Technology | Usage |
| :-- | :-- |
| [Next.js](https://nextjs.org/) | Web Frontend Framework |
| [Capacitor](https://capacitorjs.com/) | Native App Runtime |
| [Android Studio](https://developer.android.com/studio) | Emulator & APK Build |
| [react-easy-crop](https://github.com/ricardo-ch/react-easy-crop) | Image cropping interface |
| [Capacitor Filesystem](https://capacitorjs.com/docs/apis/filesystem) | Saving images on Android |

## Getting Started

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Sync with Android (Capacitor)

```bash
npx cap sync android
```
